# 样品台账设计评审（2026-11-16 冻结版）

> 评审对象：MES 质量管理 → 样品管理 → 样品台账
> 代码：`js/pages/sample-ledger.js`（单文件，类 `SampleLedger`）
> 配套：`样品管理PRD.md`（完整规格）、`docs/frontend-design-spec.md`（UI-SPL 规范）
> 本版取代 2026-11-05 版（4 态 / 7 键 / 位置树 / SAP 对账，已全部作废）

---

## 1. 一句话定位

**样品台账是 QC 样品室的实物行踪账，不是库存账。**

MES 不记库存余额，只回答四个问题：这瓶东西在哪、谁登记上架的、该不该销毁、什么时候销毁。

---

## 2. 业务前提（本轮被推翻的四个旧假设）

| 旧假设 | 实际情况（用户确认） | 设计后果 |
|---|---|---|
| 样品会被借走、调用、归还 | **不存在借还业务**，样品不出样品室 | 砍掉 `CALLED` 状态、调用/归还动作、调用记录页签 |
| 留样复测会消耗一部分 | **留样只做目检，不消耗** | 砍掉 `remainQty` 余量字段与"够不够复测"的判断 |
| 位置要管到柜/层/盒 | **只管到库存地点**，与 SAP 同颗粒度 | 砍掉位置树、占用看板、盘点；位置改为 6 个库存地点的字典 |
| 检验样品 MES 管、SAP 看不到 | **两边在过账那一刻同时下账**：SAP 331 出库，MES 从不记库存 | 不存在两个库存，也就无所谓对账 |

由此确定的核心事实：**331 是"出账"，311 是"换个库位继续保管"**。MES 台账接管的是后者的实物行踪，以及所有与 GMP 记录相关的事件。

---

## 3. 三类实物，一张表

| | 留样 RETENTION | 检验样品 INSPECT | 稳定性 STAB |
|---|---|---|---|
| 编号 | `LS-工厂-年+流水` | `类别代码-年-月-流水`（14 类） | `WD-工厂-年+流水` |
| 来源 | 取样分流（311） | 取样分流（331） | 稳定性研究模块（311） |
| 周期动作 | 目检（按频次） | 无 | 分期取样（稳定性模块记） |
| 终点 | 销毁（551） | 消耗（无凭证） | 报废（551） |
| 本台账记什么 | 存放 + 目检 + 销毁 | 存放 + 消耗闭环 | 存放 + 报废 |

**关键规则：一批要留样又要做稳定性，物理上拆两个袋、台账两条记录**，互不挪用。这样账实天然一致，不存在"这袋里的量该算给谁"。

---

## 4. 状态机：3 态

```
待入库 REG ──上架（选库存地点）──> 存放中 STORED ──处置──> 已处置 DISPOSED（只读）
```

**为什么只有 3 态**：状态只回答"东西在哪"。借还砍掉后，中间态没有存在理由。

**为什么到期不做状态**：到期是日期算出来的，不是生命周期阶段。做成状态就得靠定时任务维护，没人刷就开始撒谎。所以到期、待观察全部是派生提示：

| 诉求 | 实现 |
|---|---|
| 快到期/已过期 | 到期日列（红"已超期 N 天"、黄"N 天后到期"）+ 筛选「已过期/≤30/≤90」 |
| 该观察了 | 观察任务 `actualDate` 为空 → 状态列「待观察 N」徽章 + 筛选「待观察」 |
| 到期清单与提醒 | **不在本页做**，另做报表（用户决策） |

---

## 5. 动作：5 键，全集常显

```
上架 · 变更 · 观察 · 处置 · 查看
```

**每行完全一样，不按状态显隐、不置灰。** 不支持的操作点击时给出原因：

> 样品 WD-2001-2604001 状态为「存放中」，不支持「观察」操作（该样品非留样，不做目检）
> 样品 LS-2001-2208005 状态为「已处置」，不支持「处置」操作（已完成处置，台账只读）

支持矩阵：

| 动作 | 允许状态 | 附加条件 |
|---|---|---|
| 上架 | 待入库 | — |
| 变更 | 存放中 | 新地点不得与当前相同 |
| 观察 | 存放中 | 仅 `RETENTION` |
| 处置 | 存放中 | 留样/稳定性=销毁，检验样品=消耗 |
| 查看 | 全部 | 只读，弹窗内无操作按钮 |

---

## 6. 处置按类别分叉（不再让用户选方式）

| 类别 | 表单 | 凭证 |
|---|---|---|
| 检验样品 | 日期 + 执行人 + 说明 | 无（331 取样时已出账） |
| 留样 / 稳定性 | 日期 + 执行人 + 执行人2 + 见证人 + 销毁方式 + 销毁单号 | 551 |

处置一律**整批**，不填数量——留样不消耗、检验样品整批用完，没有"处置一部分"的业务。

---

## 7. 与 SAP 的交接口径

| 场景 | SAP 动作 | MES 动作 |
|---|---|---|
| 消耗性取样 | 331 出库，库存减少 | 建 1 条 `INSPECT`，挂 331 凭证 |
| 留样/稳定性取样 | 311 转储到留样/稳定性库位，库存不变 | 建 1 条 `RETENTION`/`STAB`，挂 311 凭证 |
| 留样/稳定性销毁 | 551 报废 | 处置登记，回写 551 凭证 |

**不设对账**：MES 没有库存余额，没有两个数可对。差异只可能来自 551 过账失败或稳定性分期未过账，靠过账状态阻断，不靠事后核对。

检验批取样是唯一的分流点（331 出账后不可逆），弹窗内一次拆成消耗 + 留样，两笔凭证原子提交。

## 8. 页面结构

**列表列**：样品编号 / 类别 / 物料·来源批次 / 检验批号 / 数量 / 存放地点 / 到期日 / 状态 / 操作

**筛选**：工厂 / 样品类别 / 检验类别 / 编号或物料 / 状态（含待观察）/ 存放地点 / 剩余天数 / 检验批号 + FilterActions

**详情（只读）页签**：
- 基本信息（含 SAP 凭证、留样豁免留痕）
- 地点变更（库存地点级流水）
- 观察记录（仅留样，NG 显示质量异常单号）
- 处置记录（销毁展示双人+见证+551；消耗展示说明）

**登记三入口**：留样登记 / 从检验批带出 / 手动登记。常规路径由取样自动建账，手工入口只用于补录与环境、验证类样品。

## 10. 请评审重点挑战

1. **3 态是否够用**：若未来出现"待复验""封存"等场景，是扩标记还是扩状态？
2. **不记余量是否可接受**：稳定性分期取样在别的模块记数量，台账不记——跨模块核对时会不会没人说得清？
3. **位置只到库存地点**：靠手写标签+编号找实物，样品量大时是否够用？
4. **处置整批**：是否存在"部分销毁/部分退回"的真实场景？
5. **取样分流不可逆**：331 出账后若发现该留样，补救路径是什么（重新取样？走偏差？）
6. **检验样品终点只有消耗**：外购/委托样需要退回供应商的，是否确实不存在？
7. **编号三套规则**（LS / WD / 类别代码）：是否推动统一？
8. **观察 NG 只生成单号不联动**：质量异常单在别的系统，这里只留号，审计是否够？
