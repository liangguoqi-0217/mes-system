## 2. 功能概述

### 2.1 一句话说明

给车间用户用的缺料排查工具：**按条件查出本车间的流程订单，把订单用到的组件按物料合并，拿订单未清数量和现有库存比，告诉车间"哪些料缺、缺多少、是哪些订单要用"**。

### 2.2 业务背景

车间排产前要确认料够不够。以往要逐个订单查组件、再逐个物料查库存，效率低。本功能把"订单查询 → 组件汇总 → 库存比对 → 缺料清单"串成一条线，一次点算即可看到本车间的缺料全貌。

### 2.3 使用角色

| 角色 | 使用场景 |
|---|---|
| 车间计划员 / 班组长 | 每日排产前查看本车间近期订单的缺料情况 |
| 车间主任 | 同时看多个资源（车间）的缺料全貌 |
| 管理员 | 跨工厂查看 |

### 2.4 范围边界

- **本期只说明检查逻辑 1（朴素逻辑）**。检查逻辑 2（SAP 标准逻辑）本期不定义，功能方案另行补充。
- **朴素逻辑的计算在 MES 侧完成**：MES 从 SAP 取回订单、组件、库存数据后，按本文第 5 章的规则在 MES 内完成汇总与缺料判定。
- **不落表**：计算结果只在当前页面有效，不写入数据库；刷新页面或重新点击计算时重新生成。
- **不涉及**：采购建议、替代料、批次库存锁定、安全库存、在途与在制数量（朴素逻辑只看"现有库存 vs 订单未清数量"）。
- **数据范围**：只看到用户有权限的工厂与资源下的流程订单。

## 3. 名词解释

| 名词 | 说明 |
|---|---|
| 流程订单 | SAP 生产订单，本功能的操作对象 |
| 组件 | 流程订单要使用的物料（BOM 展开后的下级物料） |
| 资源 | 车间。用户按资源授权，一个用户可有多个资源 |
| 需求量 | 流程订单对某组件的需求数量 |
| 提货数 | 该组件已领用 / 已提货的数量 |
| 未清数量 | **MES 计算**：需求量 − 提货数 |
| 供应 | SAP 现有库存（口径见 5.4） |
| 缺口 / 合计 | **未清数量合计 − 供应**：大于 0 为缺料，小于 0 为过剩，等于 0 为齐套 |
| 缺料清单 | 左栏按**物料**维度汇总的缺口列表 |
| 齐套 | 某物料的未清数量 ≤ 现有库存 |

**术语统一**：界面上统一称"**资源**"（不是工作中心）、"**基本开始日期**"（不是计划开始日期）。

## 5. 业务规则与计算逻辑

### 5.1 查询流程订单

在用户输入的条件之外，系统固定追加以下过滤：

1. 只取**所选工厂**下的订单。
2. 只取**已选资源**下的订单。
3. 只取**基本开始日期**落在所选区间内的订单。
4. **剔除**订单状态为以下四类的订单：已交货、已技术完成、已结算、有删除标记。
5. 产品编码、订单状态、流程订单号：填写了才过滤。

表间关联关系与字段来源以《MES 自建表设计》为准（产品物料主数据与订单产品对应；工序表记录资源，通过订单号与订单表头关联）。

### 5.2 取组件（订单 → 组件）

对**用户勾选的**流程订单取其组件清单，并剔除：

1. 已标记删除的组件行；
2. 已标记最终发货的组件行（该组件已发完，不再欠料）。

### 5.3 按物料合并

把上一步得到的组件按 **物料 + 工厂** 合并：

| 指标 | 计算方式 |
|---|---|
| 需求量 | 各订单对该物料的需求数量之和 |
| 未清数量 | 各订单的（需求量 − 提货数）之和；单行若为负数按 0 计 |
| 单位 | 取该物料的单位 |

同一物料被多个订单使用时，需求量与未清数量累加，**供应只计算一次**（库存是共用的，不按订单重复计算）。

### 5.4 取供应（现有库存）

以 **物料 + 工厂** 为条件调用 SAP 库存查询接口，取回该物料的现有库存。

- **供应口径 = 非限制使用库存 + 质检库存**；冻结库存、寄售、在途、在制均不计入。
- 按合并后的物料清单**批量**查询，不按订单逐个查询。
- 接口未返回某物料的库存记录时，该物料供应按 **0** 处理。

### 5.5 缺料判定

| 计算项 | 公式 |
|---|---|
| 缺口（合计） | 未清数量合计 − 供应 |

- 缺口 > 0 → **缺料**，显示 -N，红色
- 缺口 < 0 → **过剩**，显示 +N，绿色
- 缺口 = 0 → **齐套**，显示"齐套"，灰色

缺料清单按**缺口降序**排列：缺得最多的排最前，过剩的自然排到最后。

### 5.6 计算过程的用户感知

点击「计算是否缺料」后：按钮变为"处理中…"并禁用，右栏显示遮罩提示；计算完成后左栏出现缺料清单，并**自动选中缺口最大的物料**，右栏直接展示该物料的供需详情，同时给出"计算完成"的轻提示。

## 6. 展示要求

### 6.1 流程订单列表（右栏）

| 列 | 说明 |
|---|---|
| 复选框 | 查询结果默认全选；表头复选框为**全选本页**，翻页时其他页已勾选的保留 |
| 流程订单号 | 点击打开该订单的组件明细弹窗 |
| 产品批次 | 朴素逻辑下展示 |
| 产品编码 | 订单的产品物料号 |
| 产品描述 | — |
| 订单状态 | 如"已下达""已创建" |
| 基本开始日期 | — |
| 基本完成日期 | — |

- **朴素逻辑下不显示"检查结果"列**，保证计算前后列表的列结构、列宽、行高完全一致（颗粒度一致）。
- 分页：每页 20 / 40 / 80 条；翻页、修改每页条数、重新查询、切换物料选中都回到第 1 页。
- 无数据时显示空态提示。

### 6.2 缺料清单（左栏）

- 每条显示：物料名称、物料编码 · 单位、缺口（-900 红 / +1200 绿 / 齐套 灰）。
- 按缺口降序；**朴素逻辑下全量展示**（含齐套与过剩的物料），不提供"只看缺料"的开关。
- 点击某物料：选中该物料，右栏切换为该物料的供需详情；再点一次取消选中。
- 未计算、全部齐套、未勾选订单时显示对应提示文案（见 4.4）。

### 6.3 物料供需详情（右栏 · 选中某物料后）

**① 需求 = 各流程订单**

| 列 | 说明 |
|---|---|
| 流程订单号 | 用到该物料的订单 |
| 产品批次 | — |
| 产品编码 | — |
| 产品名称 | — |
| 需求数量 | 该订单对该物料的需求量（悬浮提示"需求 X − 已投料 Y"） |
| 未清数量 | 需求量 − 提货数 |
| 单位 | — |

**② 供应 = 现有库存**

| 列 | 说明 |
|---|---|
| 库存状态 | 非限制 / 质检 |
| 库存地点 | 库存地点编码 |
| 库存地点描述 | — |
| 数量 | 该地点的库存数量 |
| 单位 | — |

末行给出供应合计。

**③ 结果**

| 列 | 说明 |
|---|---|
| 缺口 / 过剩 | 文案与颜色 |
| 差异 | 未清数量合计 − 供应合计 |
| 单位 | — |

顶部提供"显示全部订单"入口，点击回到完整订单列表。

### 6.4 订单组件明细弹窗（点击订单号）

- 头部：产品编码、产品批次、计划期间（基本开始日期 ~ 基本完成日期）、该订单的检查结果。
- 组件表：物料、物料描述、需求数量、已投料数量、未清数量、单位、现有库存、现有库存缺口。
- 缺口说明：**未清数量 − 现有库存（非限制 + 质检）；不计在途、不扣其他订单占用、不看需求日期**。

### 6.5 其他

- **导出**：导出已勾选订单的组件明细（本期只导出组件明细，不导出缺料清单的汇总结果）。
- **查询变式**：条件组合可保存 / 套用，进入页面自动回填不自动查询。

## 7. 异常与边界处理

| 场景 | 处理 |
|---|---|
| 必填项未填 | 提示具体缺哪一项，不发起查询，不清空已有列表 |
| 基本开始日期起晚于止 | 提示区间非法，不查询 |
| 所选工厂下无可用资源 | 资源控件为空并给出提示 |
| 未勾选任何订单就点计算 | 提示"请先勾选要检查的订单" |
| 库存接口失败或超时 | 保持未计算状态，提示异常并允许重试，不产生半成品结果 |
| 接口未返回某物料库存 | 该物料供应按 0 处理，清单照常展示 |
| 提货数大于需求量 | 未清数量按 0 计，不出现负数 |
| 同一物料出现多个单位 | 按各订单原始单位分别展示，不做换算 |
| 勾选发生变化 | 清空上次计算结果，需重新计算 |
| 切换检查逻辑 | 保留已录入条件；朴素逻辑下不显示"物料编码"条件 |

## 8. 非功能要求

| 项 | 要求 |
|---|---|
| 性能 | 库存按物料批量查询，不按订单逐个查询；订单列表分页，单页最多 80 条 |
| 数据时效 | 库存为调用瞬间的快照，不落库；需要最新数据时点「刷新」重新计算 |
| 权限 | 严格按工厂 + 资源权限过滤，不允许越权查看 |
| 日志 | 记录查询条件、库存查询的物料数量与耗时，便于排查 |
| 一致性 | 与系统内其他列表页共用筛选区样式、分页控件与查询变式能力 |
