# 样品管理 PRD（样品台账 + 位置树 + 到期报表）

> 版本：v1.0（2026-11-04）
> 归属：MES V3 · 质量管理 → 样品管理
> 依据：ZSX-SMP-CNAS-023《样品管理程序》、ZSX-SOP-QC-734/735/736/737/739 取样系列 SOP、QC-R-S241《样品接收、发放及销毁台账》、QA-R-161《留样台账》
> 关联原型：`qc-sample-flow.html`（QC 样品全流程沟通页）、`js/pages/retention-sample.js`（留样台账 v2）

---

## 1. 背景与目标

SAP 库位是财务口径的逻辑仓位，无法管理到冰箱、层架、盒子、行列位。QC 部门样品数量大、形态杂（试管、瓶、盒、袋），核心痛点是**找不到样品放在哪**。

本模块解决三件事：

1. **样品定位**：输入样品编号 → 返回完整物理位置路径；反向点击位置 → 列出该位置全部在库样品。
2. **保管追溯**：登记 → 上架 → 调用/归还 → 检毕处置（返还/销毁）全程留痕，替代纸质台账 QC-R-S241。
3. **到期可视**：留样与检验样品到期情况一张报表展示，不推送。

现有留样台账（retention-sample.js v2）已是一个成熟的样品保管模块，本 PRD 以其为底座**泛化**，而非另起炉灶。

## 2. 业务边界（铁律）

| # | 边界 | 说明 |
|---|------|------|
| 1 | 检验批管结果与进度，样品台账只管物理位置与保管 | 检验样品的检验进度（待检/在检/检毕）不进本模块，禁止双头状态 |
| 2 | MES 只做事实与结果录入，不做任何审批 | 无审批流、无电子签名；审批在纸质/eQMS 完成 |
| 3 | 不接条码打印、不接任何硬件 | 定位靠键盘输入样品编号；样品标识照旧纸质样品签 |
| 4 | 到期不主动推送 | 由「样品到期报表」页展示，支持筛选/打印/导出 |
| 5 | 检毕样品去向仅「返还送检方 / 销毁」 | 不存在"检毕转留样"——留样在取样环节即已分流 |
| 6 | 编号不强行统一 | 检验样品按类别代码规则自动生成；留样沿用 LS 编号；靠检验批号关联 |
| 7 | SAP 不参与本模块 | 检验样品、稳定性样不是库存，不过账；留样的 311/551 属于留样台账，保持不动 |

**不在范围内**：标准品/对照品管理（标定、标化、使用记录）、温湿度监控、检验结果录入、稳定性样品（归稳定性方案与计划模块）、留样观察（归留样台账）。

## 3. 管理对象

样品台账管理**检验样品**，覆盖 14 类类别代码（同受控文件样品编号规则）：

| 代码 | 类别 | 代码 | 类别 |
|------|------|------|------|
| YC | 中药材及饮片 | GS | 工艺用水 |
| YF | 原辅料 | KQ | 压缩空气 |
| NBC | 内包材 | HJ | 环境监测 |
| WBC | 外包材 | YZ | 验证类 |
| CP | 成品 | WT | 外部委托 |
| ZJ | 中间产品 | KY | 科研 |
| WD | 稳定性（仅登记来源，考察归稳定性模块） | QT | 其他 |

> 稳定性样不在本模块管理；留样归「留样管理」页。

## 4. 核心概念与数据模型

### 4.1 位置树（公共主数据，js/core/sample-locations.js）

层级模型（**结构由 QC 自定，系统只定层级**）：

```
房间/样品间 → 存储设备（冰箱/留样柜/干燥器/冰柜）→ 层/搁架 → 盒 → 行列位
```

节点字段：

| 字段 | 说明 |
|------|------|
| code | 位置编码，全局唯一（如 `FRZ-01-L2-B-05`） |
| name | 名称（如"B盒"） |
| type | room / fridge / cabinet / shelf / box / slot |
| tempZone | RT 常温 / COOL 阴凉 / COLD 冷藏2~8℃ / FREEZE 冷冻 |
| parentCode | 父节点 |
| status | active / inactive（停用） |
| path | 冗余面包屑路径（`样品间1 / 3号冰箱 / 2层 / B盒`） |

停用校验：任一台账（样品/留样）仍有样品引用该节点（含子孙节点）→ 不允许停用。

### 4.2 样品台账记录（js/pages/sample-ledger.js）

```js
{
  id, sampleNo: 'YF-2026-05-018',   // 类别代码-年-月-流水号，登记时自动生成且唯一
  type: 'YF',                        // 类别代码
  plant, materialCode, materialName,
  sourceBatch,                       // SAP 批次
  inspectBatchNo,                    // 关联检验批（从检验批带出时必填）
  qty, remainQty, unit,              // 登记量 / 余量（调用消耗后扣减）
  locCode,                           // 引用位置树节点，替代手填字符串
  storageCondition, validDate,
  status,                            // REG|STORED|CALLED|CONSUMED|DESTROYED
  registerBy, registerTime, putawayTime,
  moves: [],                         // 位置变更记录 [{time, from, to, by, reason}]
  calls: [],                         // 调用记录 [{callNo, by, dept, purpose, qty, time, returnTime, returnBy}]
  disposal: {}                       // 处置记录 {mode: RETURN|DESTROY, date, by, method?, to?}
}
```

## 5. 状态机（样品台账，五态，无审批卡点）

```
待入库 REG ──上架定位──> 在库 STORED ──调用──> 调用中 CALLED ──归还──> 在库 STORED
   │                        │
   │                        ├──消耗完──> 已消耗 CONSUMED（终态，只读）
   └──检毕处置──> 已返还 / 已销毁 DESTROYED（终态，只读）
```

| 状态 | 徽章 | 说明 |
|------|------|------|
| REG 待入库 | 黄 | 已登记，待指定位置入库 |
| STORED 在库 | 绿 | 已按位置树落位 |
| CALLED 调用中 | 紫 | 被借出/复测取用，待归还或已消耗 |
| CONSUMED 已消耗 | 灰 | 余量清零（检验用掉），终态 |
| DESTROYED 已销毁 | 灰 | 销毁登记完成，终态 |

## 6. 编号规则

- **检验样品**：`类别代码-年-月-流水号`，例 `YF-2026-05-018`；流水号按类别+年月重置；登记时系统自动生成且唯一。
- **留样**：沿用现有 `LS-工厂-年月+流水` 规则，不动。
- **关联**：两套编号通过 `inspectBatchNo`（检验批号）互相可查；检验批详情侧仅展示"样品已登记"状态，不回写。

## 7. 页面功能规格

### 7.1 位置管理（新增，route: sample-location）

- 左侧树形面板（房间 → 设备 → 层 → 盒 → 位，可折叠展开）+ 右侧节点属性卡。
- 操作：新增子节点 / 编辑 / 停用（校验占用）/ 启用；编辑树结构后受影响台账的位置路径即时刷新（冗余 path 统一由 core 模块重算）。
- 每个节点显示占用计数（在库样品数），QC 一眼看出哪个盒子满没满。

### 7.2 样品台账（新增，route: sample-ledger）

**布局**：筛选栏 + 表格 + 大查看弹窗（max-width ≥1200px）。

- 筛选：工厂、样品编号/物料关键字、状态、位置、来源批次（更多条件：检验批号、登记日期区间）。
- 按钮区：FilterActions.render 五键（查询/打印/导出/我的变式/更多条件）+ 页头「+ 样品登记」。
- 列表列：样品编号 / 类别 / 物料 / 来源批次·检验批 / 登记量·余量 / 位置（面包屑）/ 登记人·时间 / 状态 / 操作。
- 行项目操作：**只留「查看」**（btn btn-blue btn-sm）；登记入口在页头。

**登记（两种方式 → 先弹选择弹窗）**：

1. 从检验批带出：选检验批 → 物料/批次/批号自动带入，类别默认按物料类型，可改；
2. 手动登记：物料从主数据选，批次、数量手填。

登记后状态=待入库，样品编号自动生成。

**查看弹窗（四页签，纯只读，底部仅「关闭」）**：

- 基本信息：编号、类别、物料、批次、检验批、数量/余量、保存条件、有效期、登记信息；
- 位置与移动：当前位置面包屑 + moves 流水表；
- 调用记录：calls 表；
- 处置记录：disposal 或占位提示。

**操作（全部在查看弹窗内，登记事实、无审批）**：

| 操作 | 入口状态 | 记录 |
|------|---------|------|
| 入库上架 | REG | 选位置树节点 → STORED |
| 位置变更 | STORED/CALLED | 选新位置 → moves 追加 |
| 调用登记 | STORED | 领用人/部门/用途/数量 → 扣余量 → CALLED |
| 归还登记 | CALLED（有余量）| 归还人/状态确认 → STORED |
| 检毕处置 | 任意非终态 | 返还（返还对象/日期）/ 销毁（方式/执行人/日期）→ CONSUMED 或 DESTROYED |

**查询定位（最高频）**：输入样品编号 → 表格定位 + 查看弹窗基本信息顶部显著展示位置面包屑。

### 7.3 留样台账（改造，不动结构）

- 登记弹窗（openRegister）的「打印条码标签」选项移除（不接硬件）；
- 入库上架弹窗（openPutaway）的留样室/柜/层/位置编码四个手填字段 → 换成位置树级联选择器（sample-locations.js 提供）；
- 表格与详情弹窗的位置展示 → 改为位置树面包屑（老数据无 locCode 时降级显示原字符串）；
- 状态机、SAP 311/551、观察/调用/销毁逻辑**零改动**。

### 7.4 样品到期报表（新增，route: sample-expiry-report）

- 聚合样品台账（validDate）+ 留样台账（dueDate），一张页只读展示，不建第三份数据。
- 筛选：工厂、来源（样品/留样）、剩余天数分档（全部 / ≤30天 / ≤90天 / 已过期）、关键字。
- 列：编号 / 来源 / 物料 / 工厂 / 到期日 / 剩余天数 / 状态 / 当前位置。
- 剩余天数分档高亮：≤30 天红 / ≤90 天黄 / 其余灰。
- FilterActions 五键；打印走 PrintHelper.printCurrentTable；导出 CSV。

## 8. 菜单结构（js/main.js）

```
质量管理
 ├─ 质量主数据（不动）
 ├─ 质量检验（不动：检验批 / 留样 / 稳定性×2）
 └─ 样品管理（新增分组）
     ├─ 样品台账        route: sample-ledger
     ├─ 位置管理        route: sample-location
     └─ 样品到期报表    route: sample-expiry-report
```

留样管理菜单保持原位（质量检验组）不迁移，避免用户找不到。

## 9. 数据流

```
检验批 ──带出物料/批次/批号──> 样品台账
位置树(core) ──引用──> 样品台账 / 留样台账
样品台账 ──到期数据──> 到期报表
留样台账 ──到期数据──> 到期报表
样品台账/留样台账 ──"已登记"状态单向可见──> 检验批（不回写）
```

## 10. 非功能与前端规范

- 列表页硬规范：FilterActions.render 五键、QueryVariant 变式（mount/restore/register）、PrintHelper 打印、分页 10/20/50。
- 弹窗：max-width ≥1200px、四页签充分利用高度、避免滚动条。
- 视觉：性冷淡极简商务风，白卡片 + 中性灰分隔线 + 藏青主色（#1E3A5F），仅状态徽章用小面积语义色。
- 位置路径一律面包屑展示（`样品间1 / 3号冰箱 / 2层 / B盒`），是本模块最具辨识度的视觉元素。
- 性能：位置树一次加载内存缓存；按位置反查用 code → 样品索引（Map）避免遍历；数据为内存 mock，无后端。
- 完成后自动 git add / commit / push。
