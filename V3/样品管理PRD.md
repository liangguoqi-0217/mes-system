# 样品管理 PRD（统一样品台账 · 3 态 · 库存地点级）

> 版本：v2.0（2026-11-04）｜v1.0 为"留样台账独立 + 样品台账 + 到期报表"三页方案，v2.0 按用户决策**合并为单一台账**
> 归属：MES V3 · 质量管理 → 样品管理（样品台账）+ 质量主数据（留样规则 / 位置管理）
> 依据：ZSX-SMP-CNAS-023《样品管理程序》、ZSX-SOP-QC-734/735/736/737/739 取样系列 SOP、QC-R-S241《样品接收、发放及销毁台账》、QA-R-161《留样台账》
> 关联：`qc-sample-flow.html`（QC 样品全流程沟通页）

---

## 1. 背景与目标

SAP 库位是财务口径的逻辑仓位，管不到冰箱、层架、盒子。QC 样品数量大、形态杂，核心痛点是**找不到样品放在哪**。

**v2.0 的关键认知**：留样与检验样品在数据模型上是同一件事——"一份实物 + 一个位置 + 一条寿命 + 一次处置"。原先分两个页面的直接后果是：**QC 查一个样品，得先知道它是留样还是检验样品，才知道去哪个页面搜**，这与"输编号查位置"的核心需求打架。

因此：**一个台账、一条类别轴**。

## 2. 业务边界（铁律）

| # | 边界 | 说明 |
|---|------|------|
| 1 | 检验批管结果与进度，样品台账只管物理位置与保管 | 禁止双头状态，不回写检验批 |
| 2 | MES 只做事实与结果录入，不做任何审批 | 无审批流、无电子签名；审批在纸质/eQMS |
| 3 | 不接条码打印、不接任何硬件 | 定位靠键盘输入样品编号；样品签照旧纸质 |
| 4 | 不做到期提醒 | 不推送、不建报表页；到期靠"到期日列 + 剩余天数筛选"体现，到期清单另做报表 |
| 5 | 样品只有两个终点 | 检验样品=消耗（331 已出账）；留样/稳定性=销毁（551） |
| 6 | 编号不强行统一 | 留样 LS、稳定性 WD、检验样品类别代码，靠检验批号关联 |
| 7 | SAP 交接只有三种凭证 | 331（消耗性取样出账）/ 311（留样·稳定性转储）/ 551（销毁报废） |
| 8 | 位置只到库存地点 | 与 SAP 同颗粒度；不做位置树、不做层级、不做盘点；实物靠手写标签定位 |

**不在范围内**：标准品/对照品管理、温湿度监控、检验结果录入、稳定性样品的分期取样（归稳定性模块，本台账只记 STAB 记录的存放与报废）。

## 3. 管理对象：一条类别轴

| category | 含义 | 编号规则 | SAP |
|---|---|---|---|
| `RETENTION` | 留样 | `LS-工厂-年+流水` | 311 登记 / 551 销毁 |
| `INSPECT` | 检验样品 | `类别代码-年-月-流水号`（YC/YF/NBC/WBC/CP/ZJ/WD/GS/KQ/HJ/YZ/WT/KY/QT 共 14 类） | 331 取样出账，处置不再过账 |
| `STAB` | 稳定性 | `WD-工厂-年+流水` | 311 转入稳定性库位 / 551 报废 |

**一批要留样又要做稳定性 → 物理上拆两个袋、台账两条记录**，各有编号、各自占库存地点、各自到期，互不挪用（业务已确认不做跨用途取用）。

稳定性样在本台账只管「存放与报废」；按时间点的取样消耗由稳定性研究模块记录，两处不重复记同一笔数量变化。

## 4. 状态机：3 态（关键设计决策）

**状态只描述"东西在哪"，不描述"快到期了""该观察了"。**

```
待入库 REG ──上架（选库存地点）──> 存放中 STORED ──处置──> 已处置 DISPOSED（终态只读）
```

| 状态 | 徽章 | 说明 |
|---|---|---|
| 待入库 REG | 黄 | 已登记，待指定库存地点 |
| 存放中 STORED | 绿 | 已落位到某个库存地点 |
| 已处置 DISPOSED | 灰 | 已销毁 / 消耗，终态只读 |

**为什么没有「借出中」**：业务上样品不出样品室，不存在借走、调用、归还；留样只做目检、不消耗，检验样品由检测动作自然消耗。`CALLED` 状态与整套借还记录随之删除，状态机从 4 态收敛到 3 态。

**为什么去掉 v1 的「即将到期 / 已到期」状态**：到期是日期算出来的结果，不是生命周期阶段。做成状态就必须靠定时任务或人工维护，一旦没人刷，状态和日期脱节，台账开始撒谎。三个终态合并为 `DISPOSED` + `disposal.mode` 字段。

腾出来的工作清单全部降级为**派生筛选**：

| 原状态 | 现表达 |
|---|---|
| 即将到期 / 已到期 | 到期日列（红色"已超期 x 天"、黄色"x 天后到期"）+ 筛选「≤30 天 / ≤90 天 / 已过期」 |
| 待观察 | 观察任务 `actualDate` 为空 + 状态列「待观察 N」徽章 + 筛选「待观察」 |

到期清单/推送不做进台账，由独立报表承接（用户已明确另做报表）。

## 5. 数据模型（一张表）

```js
{
  id, category: 'RETENTION'|'INSPECT'|'STAB', type,  // type 仅检验样品用（14 类代码）
  sampleNo, plant, materialCode, materialName, sourceBatch, inspectBatchNo,
  qty, unit, storageCondition, validDate,            // qty 为登记量，无余量概念
  locCode,                                           // 库存地点（LY-A/LY-B/WD-01/QC-01/FRZ-01/DR-01）
  status, registerBy, registerTime, putawayTime,
  locationLog: [],                                   // 上架 / 地点变更，只记库存地点
  // 留样 / 稳定性
  keepRule, dueDate, observeFreq, nextObserveDate,   // observeFreq 仅留样
  sapDocNo, sapMoveType, sapSyncTime,                // 311
  // 处置（按类别分叉，字段按 mode 显隐）
  disposal: { mode:'DESTROY'|'CONSUME', date, by1, by2, witness,
              method, no, remark, sapDoc, sapMoveType }
}
```

已删除的字段：`remainQty`（留样不消耗、检验样品整批消耗，余量无业务意义）、`calls[]`（无借还业务）、`pendingDisposal`（破损归还才产生，已无来源）、`labelNo`（标签手工书写，不进系统）、`moves[]`（降级为 `locationLog` 库存地点级）、`room/cabinet/shelf`（不做位置树）。

观察任务独立成表（仅留样）：`observeData[] { sampleId, seq, total, planDate, actualDate, observer, item, result, remark, abnormalNo }`；
留样规则独立成表：`ruleData[] { materialCode, needSample, sampleQty, storageCondition, keepRule, observeFreq, observeTimes }`。

## 6. 动作矩阵（三类同构，差异只在表单字段）

| 当前状态 | 可用动作 |
|---|---|
| 待入库 | 上架 |
| 存放中 | 地点变更 · 留样观察\* · 处置 |
| 已处置 | 只读，无动作 |

\* 观察仅留样（检验样品/稳定性点「观察」给出"非留样，不做目检"提示）

| 表单差异 | 留样 | 稳定性 | 检验样品 |
|---|---|---|---|
| 登记 | 取样分流自动建账（311）/ 留样登记 | 稳定性研究模块建账（311） | 取样分流自动建账（331）/ 从检验批带出 / 手动登记 |
| 处置方式 | 仅销毁 | 仅销毁 | 仅消耗（331 已出账） |
| 处置表单 | 执行人 + 执行人2 + 见证人 + 方式 + 551 | 同留样 | 日期 + 执行人 + 说明，无凭证 |
| 观察 | 有（4 页签，目检任务） | 无（3 页签） | 无（3 页签） |
| 数量变化 | 不消耗，整批销毁 | 分期取样由稳定性模块记录 | 检测自然消耗，整批消耗 |

### 6.1 取样用途分流（331 / 311）——与 SAP 对齐的关键设计

**业务前提**：331 = 取样出库，过账后 SAP 不再持有该实物库存；311 = 库存地点转储，实物转移到留样库位后 SAP 仍有账。**用途必须在取样环节定，事后不可逆**（331 出账后无法再 311 转回）。

检验批取样弹窗内一次性完成分流：

```
取样总量
├ 消耗性取样（331 出库）  = 总量 − 留样量，自动计算
└ 作为留样（311 转储）    = 手工填写，按留样规则带出建议值与保存条件/期限/频次
```

规则（质量主数据 → 留样规则）在此的角色：**给默认值 + 强制校验 + 派生依据**，不再驱动登记：
- 带出：建议留样量、保存条件、保存期限规则、观察频次与次数
- 强校验：`needSample=true` 的物料，留样量置 0 必须填「本批不留样豁免理由」（写入台账 `retainWaiver`）；留样量不得低于规则值（可调大不可调小）
- 派生：到期日 = 有效期 + 期限规则；观察任务按频次×次数预排

过账与建账（原子性要求）：
- 两笔凭证（331 / 311）必须同时成功，任一失败则不写台账、不改检验批状态
- 成功后自动建台账：消耗 → 1 条 `INSPECT`（挂 331 凭证，状态待入库）；留样 → 1 条 `RETENTION`（挂 311 凭证，到期日与观察任务自动生成）
- 检验批「取样记录」页签展示 消耗(331)/留样(311) 拆分与两笔凭证号

**口径（不设对账）**：331 与 311 是两系统的唯一交接点。331 出账后 SAP 与 MES 都不再持有检验样品；311 转储后两边同持留样/稳定性，之后 MES 仅记实物行踪、不建库存账。**MES 没有库存余额，因此不存在与 SAP 的定期对账**；差异只可能来自 551 过账失败或稳定性分期未过账，靠过账状态阻断，不靠事后对账。

## 7. 页面功能规格

### 7.1 样品台账（route: sample-ledger，合并后唯一台账页）

- **筛选**：工厂 / 样品类别（留样·稳定性·检验样品）/ 检验类别 / 编号或物料 / 状态（含「待观察」）/ 存放地点 / 剩余天数（已过期·≤30·≤90）/ 检验批号 + FilterActions 五键
- **表格列**：样品编号 / 类别 / 物料·来源批次 / 检验批号 / 数量 / 存放地点 / 到期日 / 状态 / 操作
- **行项目操作**（**全集常显**）：每行固定 上架 / 变更 / 观察 / 处置 / 查看 五键，不按状态显隐或置灰；当前状态不支持的操作点击时提示「样品 XX 状态为『XX』，不支持『XX』操作」
- **登记**：先弹方式选择（留样登记 / 从检验批带出 / 手动登记），再进对应表单
- **查看弹窗（只读）**：库存地点横幅 + 状态徽章 + 基本/地点变更/观察（仅留样）/处置 页签
- **页头按钮**：仅「+ 样品登记」（留样规则属质量主数据，走菜单，不占页头）

### 7.2 留样规则（route: retention-rule，质量主数据）

物料维度：是否留样 / 留样量 + 单位 / 保存条件 / 保存期限规则（有效期后 1 年、后 6 个月、放行后 3 年）/ 观察频次 / 观察次数。筛选：工厂 / 是否留样 / 物料；行内「编辑」，页头「+ 新增规则」。留样登记按本规则带出默认值，可覆盖。

### 7.3 位置管理（route: sample-location，质量主数据）

房间 → 冰箱/柜 → 层 → 盒（→ 行列位），树形维护 + 节点详情，**仅服务稳定性研究模块**（备样入箱、移库、舱位取数）。

**样品台账不再使用位置树**：台账位置只到库存地点（与 SAP 同颗粒度），位置以固定字典维护（留样室A/B、稳定性室、QC 样品间、冷库、阴凉库），不做层级、不做占用看板、不做盘点。实物定位靠样品编号与手写标签，系统只回答「在哪个库存地点」。因此台账不注册位置占用 provider，位置管理页的「反查样品」只反映稳定性样品。

### 7.4 菜单

```
质量管理
 ├─ 质量主数据：主检验特性 / 检验方法 / 取样方案 / 检验计划 / 留样规则 / 位置管理 / 目录类型管理
 ├─ 质量检验：检验批管理 / 稳定性研究 / 年度考察计划 / 稳定性数据与报告
 └─ 样品管理：样品台账
```

旧路由 `retention-sample` 保留为别名，直达合并后的台账页。

## 8. 留样专属能力（从原留样台账完整承接）

| 能力 | 落地位置 |
|---|---|
| 取样用途分流（331 消耗 / 311 留样） | 检验批取样弹窗，一次分流生成台账记录与两笔凭证 |
| 物料留样规则（是否留样/留样量/保存条件/期限规则/观察频次与次数） | 质量主数据 → 留样规则（独立页），取样与留样登记时带出 + 强校验 |
| 观察频次与任务（仅目检，不消耗） | 观察弹窗（跨次任务清单）+ 详情「观察记录」页签；NG 自动生成质量异常单号 |
| SAP 311 转储 | 取样/登记后回写凭证号，基本信息展示 |
| SAP 551 报废 | 销毁登记后回写凭证号，处置记录展示 |
| 双执行人 + 见证人销毁 | 留样与稳定性的销毁表单独有 |
| 稳定性样存放与报废 | `STAB` 类别记录；分期取样由稳定性研究模块记录，本台账不重复记数量 |

## 9. 数据流

```
检验批取样弹窗 ──331 消耗 / 311 留样分流──> 样品台账（自动建账）
留样规则 ──默认值/强校验/派生（到期日·观察任务）──> 取样弹窗 & 留样登记
稳定性研究模块 ──311 建账 / 分期取样──> 样品台账（STAB 记录只记存放与报废）
库存地点字典（6 个，与 SAP 库存地点对齐）──引用──> 样品台账
销毁/报废 ──551──> SAP（留样与稳定性）
样品台账 ──"已建账"单向可见──> 检验批（不回写）
```
