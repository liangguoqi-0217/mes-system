## 1. 决策

**MES 不做样品管理**。质量管理下删除：

| 删除项 | 原路由 | 原文件 |
|---|---|---|
| 样品台账 | `sample-ledger`（含旧别名 `retention-sample`） | `js/pages/sample-ledger.js` |

| 菜单分组「样品管理」 | — | `js/main.js` |
| 菜单项「质量主数据 → 位置管理」 | — | `js/main.js` |
| 检验批取样自动建账 | — | `js/pages/inspection-batch.js` |

## 2. 理由（业务口径）

1. **位置颗粒度只到库存地点**，与 SAP 完全一致，系统不需要再维护一套层级位置。
2. **MES 不建库存账**：SAP 有账的（留样、稳定性）SAP 自己管；SAP 无账的（检验样品，331 取样即出账）双方同时下账。没有两本账要对，也就没有台账的存在理由。
3. **无借还业务**：样品不出样品室，不借走、不调用、不归还；留样只做目检不消耗，检验样品由检测自然消耗。
4. 实物定位靠**手写标签 + 样品编号**，不需要系统指路到柜/层/盒。

## 3. 仍然保留、不要连带删错的东西

| 保留项 | 位置 | 为什么不能删 |
|---|---|---|
| 留样规则 | 质量主数据 → `retention-rule` | 检验批取样时带出默认值与强校验（必须留样、不能低于规则值、留样量为 0 需豁免理由） |
| 位置树 core | `js/core/sample-locations.js` | 稳定性研究（`stability-plan` / `stability-data`）仍按 房间→柜→层→盒 管理备样入箱与移库，是唯一消费方 |
| 取样双凭证 | `inspection-batch.js` `submitSampling` | 331（消耗性取样出账）/ 311（留样转储）仍在取样时过账，只是不再生成台账记录 |
| 取样记录页签 | 检验批详情 | 展示消耗 331 / 留样 311 拆分与两笔凭证号 |
