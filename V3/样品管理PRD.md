# 样品管理 PRD（统一样品台账 + 位置树）

> 版本：v2.0（2026-11-04）｜v1.0 为"留样台账独立 + 样品台账 + 到期报表"三页方案，v2.0 按用户决策**合并为单一台账**
> 归属：MES V3 · 质量管理 → 样品管理（样品台账）+ 质量主数据（留样规则 / 位置管理）
> 依据：ZSX-SMP-CNAS-023《样品管理程序》、ZSX-SOP-QC-734/735/736/737/739 取样系列 SOP、QC-R-S241《样品接收、发放及销毁台账》、QA-R-161《留样台账》
> 关联：`qc-sample-flow.html`（QC 样品全流程沟通页）

---

## 1. 背景与目标

SAP 库位是财务口径的逻辑仓位，管不到冰箱、层架、盒子。QC 样品数量大、形态杂，核心痛点是**找不到样品放在哪**。

**v2.0 的关键认知**：留样与检验样品在数据模型上是同一件事——"一份实物 + 一个位置 + 一条寿命 + 一次处置"。原先分两个页面的直接后果是：**QC 查一个样品，得先知道它是留样还是检验样品，才知道去哪个页面搜**，这与"输编号查位置"的核心需求打架。

因此：**一个台账、一条类别轴**。

## 2. 业务边界（铁律）

| # | 边界 | 说明 |
|---|------|------|
| 1 | 检验批管结果与进度，样品台账只管物理位置与保管 | 禁止双头状态，不回写检验批 |
| 2 | MES 只做事实与结果录入，不做任何审批 | 无审批流、无电子签名；审批在纸质/eQMS |
| 3 | 不接条码打印、不接任何硬件 | 定位靠键盘输入样品编号；样品签照旧纸质 |
| 4 | 不做到期提醒 | 不推送、不建报表页；到期靠"到期日列 + 剩余天数筛选"体现 |
| 5 | 检毕样品去向仅「返还 / 消耗 / 销毁」 | 不存在"检毕转留样"——留样在取样环节即已分流 |
| 6 | 编号不强行统一 | 留样 LS 编号，检验样品类别代码编号，靠检验批号关联 |
| 7 | SAP 只有留样过账 | 留样 311（入库）/ 551（销毁）；检验样品不是库存，不过账 |
| 8 | 位置树结构由 QC 自定 | 系统只定层级模型，编码规则不替用户设计 |

**不在范围内**：标准品/对照品管理、温湿度监控、检验结果录入、稳定性样品（归稳定性模块）。

## 3. 管理对象：一条类别轴

| category | 含义 | 编号规则 | SAP |
|---|---|---|---|
| `RETENTION` | 留样 | `LS-工厂-年+流水` | 311 / 551 |
| `INSPECT` | 检验样品 | `类别代码-年-月-流水号`（YC/YF/NBC/WBC/CP/ZJ/WD/GS/KQ/HJ/YZ/WT/KY/QT 共 14 类） | 不过账 |

稳定性样归稳定性模块，不进本台账。

## 4. 状态机：4 态（关键设计决策）

**状态只描述"东西在哪"，不描述"快到期了""该观察了"。**

```
待入库 REG ──入库上架──> 在库 STORED ──调用──> 借出中 CALLED ──归还──> 在库
                 │                                  │
                 └──────────处置登记────────────────┴──> 已处置 DISPOSED（终态只读，附处置方式）
```

| 状态 | 徽章 | 说明 |
|---|---|---|
| 待入库 REG | 黄 | 已登记，待从位置树指定位置 |
| 在库 STORED | 绿 | 已按位置树落位 |
| 借出中 CALLED | 紫 | 被取用/复测，待归还 |
| 已处置 DISPOSED | 灰 | 已销毁 / 返还 / 消耗，终态只读 |

**为什么去掉 v1 的"即将到期/已到期"状态**：到期是日期算出来的结果，不是生命周期阶段。做成状态就必须靠定时任务或人工维护，一旦没人刷，状态和日期脱节，台账开始撒谎。同样道理，v1 的"已消耗/已返还/已销毁"三个终态合并为 `DISPOSED` + `disposal.mode` 字段。

腾出来的工作清单全部降级为**派生筛选**：

| 原状态 | 现表达 |
|---|---|
| 即将到期 / 已到期 | 到期日列（红色"已超期 x 天"）+ 筛选「≤30 天 / ≤90 天 / 已过期」 |
| 待观察 | 观察任务 `actualDate` 为空 + 筛选「待观察」 |
| 待处置（归还破损） | `pendingDisposal` 标记 + 筛选「待处置」 |

旧数据映射：`EXPIRING/EXPIRED → STORED`（保留 dueDate）；`CONSUMED/RETURNED/DESTROYED → DISPOSED` + 对应 mode。

## 5. 数据模型（一张表）

```js
{
  id, category: 'RETENTION'|'INSPECT', type,   // type 仅检验样品用（14 类代码）
  sampleNo, plant, materialCode, materialName, sourceBatch, inspectBatchNo,
  qty, remainQty, unit, storageCondition, validDate,
  locCode, status, registerBy, registerTime, putawayTime,
  moves: [], calls: [],                        // 位置移动 / 调用，两类共用
  pendingDisposal,                             // 归还破损待处置标记
  // 留样专属
  keepRule, dueDate, observeFreq, nextObserveDate, labelNo,
  sapDocNo, sapMoveType, sapSyncTime,          // 311
  room, cabinet, shelf, location,              // 兼容旧字段（由位置树回写）
  // 处置（两类共用，字段按 mode 显隐）
  disposal: { mode:'DESTROY'|'RETURN'|'CONSUME', date, by1, by2, witness,
              method, qty, reason, target, remark, no, sapDoc, sapMoveType }
}
```

观察任务独立成表（仅留样）：`observeData[] { sampleId, seq, total, planDate, actualDate, observer, item, result, remark, abnormalNo }`；
留样规则独立成表：`ruleData[] { materialCode, needSample, sampleQty, storageCondition, keepRule, observeFreq, observeTimes }`。

## 6. 动作矩阵（两类同构，差异只在表单字段）

| 当前状态 | 可用动作 |
|---|---|
| 待入库 | 入库上架 |
| 在库 | 位置变更 · 调用登记 · 留样观察\* · 处置登记 |
| 借出中 | 归还登记 · 位置变更 |
| 已处置 | 只读，无动作 |

\* 观察仅留样渲染

| 表单差异 | 留样 | 检验样品 |
|---|---|---|
| 登记 | 留样登记（规则带出 + 311） | 从检验批带出 / 手动登记 |
| 调用消耗勾选 | 无 | 有（勾选且余量清零 → 直接已处置） |
| 处置方式 | 仅销毁 | 销毁 / 返还 / 消耗 |
| 销毁表单 | + 执行人2 + 见证人 + 551 凭证 | 单执行人、不过账 |
| 观察 | 有（页签 + 录入） | 无 |

## 7. 页面功能规格

### 7.1 样品台账（route: sample-ledger，合并后唯一台账页）

- **筛选（第一行）**：工厂 / 样品类别 / 编号或物料 / 状态（含「待观察」「待处置」）+ FilterActions 五键
- **更多条件**：存放位置 / 检验批号 / 来源批次 / 剩余天数（已过期·≤30·≤90）/ 登记日期区间
- **表格列**：样品编号 / 类别 / 物料 / 批次·检验批 / 数量·余量 / 存放位置（面包屑）/ 到期日 / 状态 / 操作
- **行项目操作**（同检验批管理模式，**全集常显**）：每行固定 上架 / 变更 / 调用 / 归还 / 观察 / 处置 / 查看 七键，不按状态显隐或置灰；当前状态不支持的操作点击时提示「样品 XX 状态为『XX』，不支持『XX』操作」
- **登记**：先弹方式选择（留样登记 / 从检验批带出 / 手动登记），再进对应表单
- **查看弹窗（只读）**：位置面包屑横幅 + 状态徽章 + 5 页签：基本信息 / 位置与移动 / 调用记录 / 观察记录（仅留样，含"录入观察"入口）/ 处置记录
- **页头按钮**：仅「+ 样品登记」（留样规则、位置管理属质量主数据，走菜单，不占页头）

### 7.2 留样规则（route: retention-rule，质量主数据）

物料维度：是否留样 / 留样量 + 单位 / 保存条件 / 保存期限规则（有效期后 1 年、后 6 个月、放行后 3 年）/ 观察频次 / 观察次数。筛选：工厂 / 是否留样 / 物料；行内「编辑」，页头「+ 新增规则」。留样登记按本规则带出默认值，可覆盖。

### 7.3 位置管理（route: sample-location，质量主数据）

房间 → 冰箱/柜 → 层 → 盒（→ 行列位），树形维护 + 节点详情；节点显示在库占用数；停用前校验含子孙节点无在库样品。

### 7.4 菜单

```
质量管理
 ├─ 质量主数据：主检验特性 / 检验方法 / 取样方案 / 检验计划 / 留样规则 / 位置管理 / 目录类型管理
 ├─ 质量检验：检验批管理 / 稳定性研究 / 年度考察计划 / 稳定性数据与报告
 └─ 样品管理：样品台账
```

旧路由 `retention-sample` 保留为别名，直达合并后的台账页。

## 8. 留样专属能力（从原留样台账完整承接）

| 能力 | 落地位置 |
|---|---|
| 物料留样规则（是否留样/留样量/保存条件/期限规则/观察频次与次数） | 质量主数据 → 留样规则（独立页），留样登记时带出 |
| 观察频次与任务 | 「观察记录」页签 + 录入观察（异常可一键发起质量异常） |
| SAP 311 入库过账 | 留样登记后回写物料凭证号，基本信息页签展示 |
| SAP 551 销毁过账 | 销毁登记后回写凭证号，处置记录页签展示 |
| 双执行人 + 见证人销毁 | 销毁表单按类别显隐 |

## 9. 数据流

```
检验批 ──带出物料/批次/批号──> 样品台账（检验样品）
留样规则 ──带出留样量/期限/频次──> 样品台账（留样）
位置树(core) ──引用──> 样品台账（两类共用）
样品台账 ──占用统计/反查──> 位置管理
留样登记/销毁 ──311/551──> SAP（仅留样）
样品台账 ──"已登记"单向可见──> 检验批（不回写）
```

## 10. 前端规范与验证

- 列表页：FilterActions 五键、QueryVariant 变式、PrintHelper 打印、分页 10/20/50。
- 弹窗：modal-lg 以上；页签充分利用高度。
- 视觉：性冷淡极简商务风，藏青主色 #1E3A5F，仅状态徽章与到期提示用小面积语义色。
- 位置路径一律面包屑（`留样室A / A-03柜 / 2层`），是本模块最具辨识度的视觉元素。
- 占用统计采用供应商模式：`SampleLocations.addProvider(...)`，**脚本加载即注册**（不依赖是否打开过台账页）。
- 回归验证：`node` 假 DOM 冒烟脚本覆盖 9 组 39 项断言（位置树/4 态模型/留样登记 311/上架与位置变更/调用归还/观察/销毁 551/检验样品差异/派生筛选），全部通过。
