## 产品概述

登录页定稿后，重做小程序首页目录原型。因用户明确小程序功能将随 PC 端扩展而不断膨胀（未来会加入生产管理、质量管理等业务域），需提供两套目录组织方案对比，且都具备面向未来扩容的机制。

## 核心功能

- **方案A · 工作台式首页**：自上而下依次为欢迎区（问候语+品牌）、扫一扫大按钮（核心高频入口）、待办提醒卡（待处理工单/通知单数量徽章）、常用功能六宫格（设备信息/维修通知单/维修工单/库存查询/故障代码/预防性维护）、「全部功能」入口（进入完整分组目录页，承载未来庞杂功能的扩展区）
- **方案B · 业务域分组式首页**：品牌区 + 扫码入口 + 按业务域分组的功能列表（设备管理：设备信息/故障代码；维修管理：维修工单/维修通知单/预防性维护；库存管理：库存查询；预留灰度占位分组：生产管理、质量管理），分组可折叠
- **新增「全部功能」分组目录页**：完整展示所有业务域分组及其功能项，是方案A扩展入口的落地页，也作为方案B列表的完整形态
- **方案对比切换**：首页底部临时切换器（方案A / 方案B），点击即时切换两套视图，供用户对比后选定
- 单页导航、无底部 Tab；所有功能卡片点击进入现有功能页；现有功能页与登录页逻辑保持不变
- 界面风格与现有小程序一致：IBM Carbon 极简商务风（中性灰基底、白色卡片、品牌蓝强调、克制留白），移动端布局

## 技术栈

- 沿用现有单文件原型技术：HTML + CSS + 原生 JavaScript，无构建工具、无外部框架
- 完全复用现有 IBM Carbon Design System 变量（`--cds-blue-60`、`--cds-gray-*` 等）与页面切换机制（`.page` + `navigateTo()`）

## 实现方案

### 总体策略

在 `d:\我的项目\MES系统\miniapp\device-info.html` 中重做 `#page-home` 为双视图容器（方案A工作台视图 + 方案B分组列表视图，由临时切换器控制显隐），并新增 `#page-all`（全部功能分组目录页）。现有 4 个功能页、登录页、登录成功跳转逻辑零改动，仅新增/调整首页与导航映射。

### 关键决策

1. **双视图共存于 `#page-home`**：`home-view-a` 与 `home-view-b` 两个子块，通过 `.show`/隐藏切换，避免新增页面影响导航逻辑
2. **导航扩展**：`pageTitles` 增加 `all: '全部功能'`；`navigateTo('all')` 时显示返回按钮（返回首页），与现有 device 等页行为一致
3. **可扩展机制**：

- 方案A：高频功能固定 6 宫格 + 「全部功能」入口，未来新增功能只追加到「全部功能」分组目录，宫格保持精简
- 方案B：分组列表天然按业务域扩展，预留「生产管理」「质量管理」灰度占位分组（置灰 + 「敬请期待」），体现扩容方向

4. **临时切换器**：沿用登录页多版本对比模式，首页底部放「方案A / 方案B」胶囊切换器（原型工具，用户选定后移除）
5. **页面数据驱动**：功能分组与宫格项建议用 JS 数组渲染（`homeGroups`、`homeGridItems`），未来加功能只改数组，不改 HTML

### 性能与可靠性

- 纯静态原型交互，无网络请求；切换仅显隐 DOM，无性能开销
- 不改动现有 4 个功能页 HTML 与业务 JS，控制改动范围
- 切换器与分组占位为原型工具，最终选定方案后一次性清理

## 设计风格

延续已定稿登录页的 IBM Carbon 极简商务风：中性灰基底（浅灰页面底 + 白色卡片）、单一克制的品牌蓝 #0f62fe 强调、克制留白、8px 间距网格，移动端单列布局。

## 页面规划

### 方案A · 工作台式首页（自上而下 5 个功能块）

1. **欢迎区**：浅灰背景，小号标签语「BUCHANG INTELLIGENT MANUFACTURING」+ 深蓝标题「步长智造平台」+ 右侧问候语（如"上午好，张工"），与登录页品牌区风格呼应
2. **扫一扫大按钮**：全宽品牌蓝主按钮（高 56px），内嵌扫码图标 + 「扫一扫 识别设备」，置于欢迎区下方，视觉焦点
3. **待办提醒卡**：横向两张白卡（待处理工单 / 待处理通知单），左侧图标 + 名称 + 数量徽章（红色语义色，克制小面积）
4. **常用功能六宫格**：2 列 × 3 行白卡网格，每卡图标 + 名称，点击进入对应功能页
5. **全部功能入口**：浅灰底列表行「全部功能」+ 箭头，进入 #page-all 分组目录

### 方案B · 业务域分组式首页（自上而下 4 个功能块）

1. **品牌区 + 扫码行**：紧凑品牌区 + 右侧扫码图标按钮
2. **分组功能列表**：多个分组（分组标题 + 功能项列表，白卡内联），分组可折叠展开/收起
3. **预留分组占位**：生产管理、质量管理两组，灰色置灰 + 「敬请期待」标签，示意扩容方向
4. **底部版本信息**：次要灰小字

### 全部功能页 #page-all

- 顶部为搜索框（原型示意）+ 分组标题索引
- 完整分组目录：设备管理 / 维修管理 / 库存管理（实功能）+ 生产管理 / 质量管理（占位），分组卡片可折叠
- 点击功能项进入对应功能页
