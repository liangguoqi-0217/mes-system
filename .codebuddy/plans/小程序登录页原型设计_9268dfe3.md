## 用户需求

为现有小程序高保真原型（`miniapp/device-info.html`，单文件 HTML，内含 5 个页面）补齐登录界面，作为应用的启动页。

## 产品概述

- 在现有单文件原型中新增「登录」页面，作为默认启动页（打开原型先看到登录页，登录成功后进入首页）
- 界面风格与现有 IBM Carbon Design System 风格保持一致，适配移动端布局

## 核心功能

- 登录方式切换：支持「手机号登录」与「账号密码登录」两种方式，通过 Tab 切换
- 手机号登录表单：手机号输入框 + 验证码输入框 + 获取验证码按钮（点击后 60 秒倒计时、按钮禁用并显示剩余秒数）+ 登录按钮
- 账号密码登录表单：账号输入框 + 密码输入框 + 登录按钮
- 登录按钮：点击后做非空校验（手机号需为 11 位），约 0.6 秒模拟验证后跳转至首页
- 辅助入口：取消「忘记密码」「注册账号」（用户已明确不需要）
- 不增加微信一键登录等其他登录方式
- 「退出登录」入口作为可选增强（用户表示可在后续原型中考虑，不纳入本次必做范围）

## 技术栈

- 沿用现有原型技术：单文件 HTML + CSS + 原生 JavaScript，无构建工具、无外部框架
- 完全复用现有 IBM Carbon Design System 设计变量（`--cds-blue-60`、`--cds-gray-*` 等）与已有组件类（`.cds-btn-primary`、`.cds-input`、`.cds-toast` 等）

## 实现方案

### 总体策略

在 `d:\我的项目\MES系统\miniapp\device-info.html` 的 `.pages-wrapper` 内新增 `#page-login` 页面，作为默认启动页（`active`），登录成功后调用现有 `navigateTo('home')` 进入首页。对现有 5 个页面结构零侵入，仅做最小化逻辑调整。

### 关键决策

1. **页面结构复用**：新增的登录页复用现有 `.page` 容器机制（absolute 定位、`.active` 切换、纵向滚动），登录页专属样式以 `login-` 前缀命名，避免与现有类冲突。
2. **启动页调整**：`#page-login` 加 `active`，`#page-home` 移除默认 `active`；`pageTitles` 增加 `login` 条目；`navigateTo('login')` 时隐藏返回按钮（与 home 行为一致）。
3. **登录页布局**（自上而下）：

- 品牌区：深色背景（`--cds-gray-100`），沿用首页 hero 风格，展示「BUCHANG INTELLIGENT MANUFACTURING」标签语与「步长智造平台」标题
- 登录方式切换 Tab：手机号登录 / 账号密码登录（Carbon 风格分段控件，当前项蓝色高亮 + 下划线指示）
- 表单区：白色卡片（`--cds-layer-01`），两种模式共用登录按钮
- 底部：版本信息小字（次要文字色）

4. **交互逻辑**（新增 `login` 相关 JS 函数，置于导航逻辑附近）：

- Tab 切换：显示/隐藏对应表单字段组
- 获取验证码：点击后启动 60s 倒计时（`setInterval`），按钮文案变为「重新获取(59s)」并禁用；倒计时结束恢复；切换页面时清理定时器防止泄漏
- 登录提交：校验手机号格式（11 位）/账号/密码/验证码非空，错误用现有 `#cdsToast` 提示；通过后按钮显示「正在登录...」并禁用，约 0.6s 后 `navigateTo('home')`
- 输入框聚焦时蓝色边框焦点态，与现有 `cds-input` 风格一致

### 性能与可靠性

- 全部为纯静态原型交互，无网络请求、无数据持久化，开销可忽略
- 倒计时定时器在登录成功/页面切换时统一清理，避免重复计时
- 不改动现有 5 个页面的 HTML 与业务逻辑，控制改动范围（仅新增页面块 + 少量导航逻辑调整）

## 实施说明

- 新增 CSS 追加在现有 `<style>` 块末尾（`</style>` 前），不修改已有样式规则
- 新增 HTML 块插入 `.pages-wrapper` 内 `#page-home` 之前；JS 函数插入「Navigation」区域附近，保持代码组织一致
- 复用现有字体栈（IBM Plex Sans + PingFang SC）与 8px 间距网格，保证视觉一致性
- 完成后按用户惯例执行 git add / commit / push

## 架构设计

改动为单页面内新增一个视图 + 少量导航逻辑扩展，结构简单，无需架构图。数据流：登录页表单交互（Tab 切换/倒计时/校验）→ 模拟登录成功 → `navigateTo('home')` 切换到现有首页，全流程复用现有 `.page` 切换机制。

## 关键代码结构

新增 JS 接口（意图描述，实现细节以现有代码风格为准）：

- `switchLoginMode(mode)`：`'phone' | 'account'` 两种模式切换，控制对应表单字段组的显示
- `sendSmsCode()`：校验手机号后启动 60s 倒计时，期间按钮禁用并显示剩余秒数
- `handleLogin()`：表单非空与格式校验（toast 报错）→ 按钮 loading 态 → 0.6s 后 `navigateTo('home')`
- 启动时 `currentPage` 初始值保持 `'home'`，但 `#page-login` 为默认显示页，登录成功前不触发首页刷新逻辑

## 设计风格

延续现有 IBM Carbon Design System 极简商务风，与原型 5 个页面保持视觉一致：中性灰基底（浅灰 #f4f4f4 页面底、白色卡片）、单一克制的品牌蓝 #0f62fe 强调色、深色品牌区衬托。整体冷静克制，符合制造业工业质感。

## 页面规划（仅登录页）

登录页自上而下分为 5 个功能块：

1. **品牌区**：深色背景（#161616）留白充足，顶部小号字母间距标签语「BUCHANG INTELLIGENT MANUFACTURING」，下方大号加粗标题「步长智造平台」，与首页 hero 呼应，建立品牌认知。
2. **登录方式切换 Tab**：白底卡片内顶部分段式切换「手机号登录 / 账号密码登录」，当前项品牌蓝文字 + 2px 下划线指示条，切换有平滑过渡动画，点击区域不小于 44px 适配手指操作。
3. **手机号登录表单**：手机号输入框（11 位数字键盘、蓝色焦点边框）+ 验证码行（验证码输入框与「获取验证码」次级按钮并排，按钮点击后倒计时禁用态置灰显示秒数）。
4. **账号密码登录表单**：账号输入框 + 密码输入框（密码带明文切换眼睛图标可选）。两种模式切换时表单内容平滑切换，共用登录按钮。
5. **登录按钮与底部区**：全宽品牌蓝主按钮（高 48px、圆角适中），hover/按下有深浅反馈；点击后「正在登录...」loading 态；底部居中次要灰小字版本信息，增强完成感。

## 交互与响应式

- 登录方式 Tab 点击切换对应表单，切换带 200ms 淡入过渡
- 输入框聚焦：边框变品牌蓝并带浅蓝光晕，符合 Carbon focus 规范
- 错误输入：toast 轻提示 + 输入框红色描边（--cds-support-error）
- 验证码倒计时按钮：60s 内禁用置灰、实时刷新秒数，结束后恢复可点
- 全部交互在 402×874 手机框内完成，布局自适应，无横向滚动
